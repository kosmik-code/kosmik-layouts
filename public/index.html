      How to reach OBS

      Kosmik Layouts talks to OBS through its WebSocket server (built into OBS 28 and newer).

      Connection
      127.0.0.1 when OBS is on this PC. For another PC, its local IP (e.g. 192.168.1.20).
      Leave empty to keep the saved one. If OBS has authentication off, leave it empty.
      Where do I find these in OBS?
      1. In OBS: Tools › WebSocket Server Settings.
      2. Tick “Enable WebSocket server”. The port is right below it.
      3. Click “Show Connect Info”: it shows the server IP, port and password, each with a copy button.
      4. OBS on another PC: allow OBS through that PC's firewall the first time Windows asks.
